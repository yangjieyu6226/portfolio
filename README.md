## 首页鼠标追光

鼠标在首页移动时，亮区屏幕半径为 200px，保持原稿亮度，向外柔和过渡至 50% 黑色遮罩；不叠加白色滤镜，不改素材。追光是舞台独立层，位于首页导航及马赛克轨迹上方、作品及档案弹层下方，不参与唱片机变换、不拦截任何 hover 或点击。既有马赛克依旧显示，光圈外同样被柔和压暗。坐标和光圈尺寸随舞台缩放换算，窄屏时仍保持 200px 屏幕半径。

光圈使用 400ms 时间常数的指数缓动追随鼠标，鼠标停下后光圈继续柔和追上；快速反向移动从当前亮区衔接，不排队延迟动画。首亮及重新回到首页时从当前鼠标位置开始，避免从旧页面位置飞入。按真实帧间时间计算，常规 60Hz/120Hz 下跟随节奏相同；追上到 0.25 屏幕像素内即停止帧循环。

首页与作品区切换时，蒙层透明度随现有唱片机动画的实时滚动进度连续变化：下滑逐渐淡出，上滑逐渐淡入，起止均以 `smoothstep` 放缓；沿用约 1.05 秒的整段导航，不在起步或归位时突然开关。快速反向滚动沿当前进度衔接，不另起淡入/淡出定时动画。作品区完全展开后透明度为零、效果层隐藏并停止跟随；原生滚动也按同一段页面距离换算透明度。

个人档案与作品详情（含打开、关闭过渡）仍不显示追光。鼠标移出舞台、窗口失焦、页面重新显示、触摸操作或键盘 Tab 导航时，只收起亮区，首页保留 50% 黑色蒙层；触屏和“减少动态效果”模式不启用。这些状态会取消未完成的跟随帧，鼠标更新仍按帧合并。

## 首页 → 作品轮播

轻轻向下滚动一次，原有唱片机自动完整放大到约 1.33 倍并右移；向上滚动一次会自动完整收回。连续同方向的滚动不会重启动画，反向操作会从当前位置平滑返回。顶部导航不参与缩放，点击 WORK / PORTFOLIO 也能切换到作品 / 首页；作品卡片展开后，点击右侧空白处同样可以收回。ABOUT / CONTACT 均打开现有信息卡，从作品区点击时会先自然返回首页再打开。

作品展开和切换途中，底部原有蓝白吊牌仍响应 hover，但点击/键盘不会再打开个人档案弹层；完整回到首页后恢复打开功能。

轮播共五张，默认露出中间一张及上下两张。悬停上方 / 下方会沿圆弧循环切换，移出后完成当前一次切换即停。也支持点击上下区域或聚焦后使用方向键；系统开启“减少动态效果”时关闭连续悬停轮播。

悬停中间的抖音、联想或第四张趣野卡片时，原蓝色唱片在 640ms 内右移出画面，对应的粉色抖音唱片、橙色联想唱片或黄绿色趣野唱片在原位置渐显（错开 160ms 开始，总时长约 720ms）。移出、切换作品、打开详情或收回首页后平滑复原。只移动唱片的独立位移容器，不移动银色转盘、中心轴、唱臂、固定热点或导航；原蓝盘及三张项目盘沿用相同的持续旋转角度。换盘由一个动画控制器管理，快速移入移出与跨项目切换从当前状态衔接，不重置角度、不叠加动画；减少动态效果时取消位移，直接切换样式。

替换图片：修改 `work-carousel.js` 顶部 `WORK_CARDS` 五项的 `src` 和 `alt`。推荐图片比例 **775:436**；空路径保留占位卡片，`coverColor` 可指定颜色，图片放入 `assets` 即可。第一张使用抖音原始卡片切图，第二张联想使用上传原图 `assets/work-card-02.png`（823×484，原文件与透明通道不变）；`coverInset: 24` 对齐导出边缘内的 775×436 主体，仅在既有卡框内显示，不缩小卡面。`coverImageBackground: "transparent"` 使图片加载后不垫橙色，加载失败仍保留原稿橙色 #fd7214 占位。第三张百度使用上传封面 `assets/work-card-03.png`（775×484，原比例居中铺满现有卡片）。蓝色 #0351ff 保留为图片加载失败时的底色。第四张趣野使用上传原图 `assets/work-card-04.png`（775×436，无裁切），hover 光盘为 `assets/work-record-quye.png`（1061×1061，保留透明背景）。封面替换不影响对应详情。

动画依赖已保存在 `vendor`，直接打开 `index.html` 也可使用，无需联网加载动画库。

## 详情页轻交互

五个作品共用详情动效：完整卡片/编组从下方 96px 上浮，单段 1.4 秒、`sine.inOut` 慢起慢落。同一叠卡单元的各层错开 180ms；卡片在视口中露出约 20% 视口高度后开始播放（较短单元以自身高度为上限），上下滚动都按原始卡片边界判断，避免动效在屏幕边缘提前播完。卡片及其 96px 位移包络完全滚出视野、超过 64px 缓冲后重新准备，避免重置时卡片尾部闪回；第二次滚入会再次播放。恢复阅读位置或异步加载时，当前画面直接可见，不重新移动正在阅读的内容。

抖音作品使用 Figma 原稿导出的完整 SVG 图层进行渐进增强，不再按横条切长图。蓝、粉、黑色卡片依次上浮；后续内容按完整卡片/编组移动。图层路径、字体轮廓、遮罩和最终位置均保留原稿。

抖音的六片背景模糊为 Figma 导出的 HTML `foreignObject`。两片大型模糊位于完全不透明的原稿纸底下，另四片是局部效果；它们会增加超长 SVG 动画的合成负担。运行时先严格核对六片模糊及剪裁引用，再仅从动画副本中省去这些 HTML 模糊面；原始 Figma SVG、完整 PNG、纸底、手机、文字和卡片图层均保持不变。结构校验失败时直接保留完整 PNG。局部半透明气泡在上浮期间会少一些背景虚化，静止状态仍显示原稿 PNG。

首屏已露出的抖音 Logo 属于完整 `intro-content` 编组，判定范围为 721–2163px；它与尚未进入视口的三层纸张使用独立状态，避免打开时已可见内容先跳下 96px，同时保留蓝、粉、黑纸的首次错序入场。`solution-stack` 顶部范围修正为 5208px，包含突出纸底的 Logo。再次滚入仍沿用完整单元边界与位移包络判断，不测量每帧的 SVG 几何。

联想作品的 19 个完整章节编组同样支持上浮与再次滚入播放，封面和长稿中的装饰背景保持原位。`work-carousel.js` 的 `LENOVO_REVEAL_CARDS` 按原始 Figma 编组绑定，不切开手机、卡片或文字。不同作品分别提供尺寸和图层映射，共用详情交互控制器。

百度作品的 `BAIDU_REVEAL_CARDS` 绑定 9 个完整编组单元；KR2 白色底卡和内容一起移动，文字和图表不被横向切开。封面保持原位，后续编组沿用上浮、重复滚入播放和独立阅读位置。可运行 `node tools/prepare_detail_svg.cjs baidu-layered` 重新无损准备百度 SVG 图片资源。

趣野的 `QUYE_REVEAL_CARDS` 绑定 18 个完整章节或卡片单元，沿用上述共享动效。灰色叠卡按上中下、AI 手机按左中右错开 180ms，手机截图和外壳不分离，其余章节保持完整根编组。父组与子组不重复绑定；封面、长背景和未绑定的标签保持原位。原 SVG 导出尺寸为 1668×21190，加载校验允许不足 0.5px 的原稿小数取整，同时沿用精确逻辑展示高度，避免静态与分层内容切换时跳动。

第五张 AI 效率实践的 `AI_EFFICIENCY_REVEAL_CARDS` 绑定 4 个完整原稿编组：流程图、结果验证，以及底部左右两部分；最后两部分错开 180ms，其他交互参数与重复滚入逻辑沿用原控制器。最新 SVG 保留修订后的文字轮廓、图像和遮罩，首屏和长背景不参与位移。`ai-efficiency-layered-v2-offline.js` 保证直接打开本地 HTML 时也能读取同一份新版分层源，加载失败或减少动态效果时保留最新版完整静态 PNG。

五个作品在卡片即将进入视口或正在上浮时使用分层 SVG；这轮上浮结束后自动回到原始完整 PNG，防止浏览器漏绘超长 SVG 时持续显示空白。关闭详情或系统开启“减少动态效果”时，会清理动效并恢复原始完整 PNG。没有 GSAP、SVG 加载失败时，也保留静态原图。`layeredArtwork` 指向分层资产，`revealCards` 可提供每件作品的完整图层配置；不填写时沿用 `work-detail-motion.js` 的抖音 `CARDS`。所有五个作品均有同源离线 SVG 字符串，直接打开本地 HTML 时无需依赖 `file://` 的 fetch 支持：抖音、联想、百度通过 `layeredArtworkBundle` 在打开对应详情时按需加载，不增加首页初始化的素材读取；趣野和 AI 效率实践沿用已有脚本。离线源成功后共享复用，失败可在下次打开时重试。页面切到后台时停止动效调度；关闭详情会中止 SVG 请求并清理动画，即使共享离线脚本稍后加载完成，也不会更新已关闭的详情。

`node tools/prepare_detail_svg.cjs` 默认准备抖音，`node tools/prepare_detail_svg.cjs lenovo-layered-v2` 准备最新联想稿；均从原始导出 SVG 无损提取嵌入图片，不修改原图像素。更新趣野资产后依次运行 `node tools/prepare_detail_svg.cjs quye-layered`、`node tools/prepare_offline_artwork.cjs quye-layered quye`，保持分层资产与离线源同步。

更新前三个作品的分层源后，分别运行 `node tools/prepare_offline_artwork.cjs douyin-layered douyin`、`node tools/prepare_offline_artwork.cjs lenovo-layered-v2 lenovo`、`node tools/prepare_offline_artwork.cjs baidu-layered baidu` 同步按需加载的离线包。

更新 AI 效率实践原稿后依次运行 `node tools/prepare_detail_svg.cjs ai-efficiency-layered-v2`、`node tools/prepare_offline_artwork.cjs ai-efficiency-layered-v2 ai-efficiency`，保持第五张作品的分层资源与离线数据同步。更新时采用新的资产版本和脚本缓存标识，避免静态长图与动画显示不同版本的文字。

详情页沿用首页的鼠标马赛克画布：黑白为主、少量蓝色与粉紫色，覆盖详情内容但不截获点击、滚动或拖动；触屏及“减少动态效果”模式不显示轨迹。
